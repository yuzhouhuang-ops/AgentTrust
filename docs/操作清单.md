# 第 0 步：用正确的方式打开项目

### 为什么要这样做

上次你报错 "无法识别 .venv\Scripts\python.exe"，原因就是**终端站错了文件夹**。
用下面这个方法打开，VS Code 会**自动帮你站到正确的文件夹**，这个问题就永远不会再出现。

### 要做什么

| 序号 | 操作 | 说明 |
|---|---|---|
| 0-1 | 打开 VS Code | |
| 0-2 | 点菜单 **`文件` → `打开文件夹...`** | 不要用"打开文件"，要用"打开文件夹" |
| 0-3 | 在弹出的框里，地址栏粘贴：`C:\项目\projects\agenttrust` | 然后点「选择文件夹」 |
| 0-4 | 左侧会出现文件列表 | 看到 `app`、`tests`、`README.md` 等 |

### ✅ 应该看到

左侧文件树长这样（缺几个没关系，关键是 `app` 和 `tests` 在）：

```
AGENTTRUST_CONTEXT_FOR_CODEX.md
app
  experiment.py
  main.py
  scoring.py
  simulator.py
  strategies.py
LEARN.md
pyproject.toml
README.md
requirements.txt

run_experiment.py

```

### ❌ 出错怎么办

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 看不到 `app` 文件夹 | 打开的是上层目录（比如打开成了 `C:\项目`） | 重新执行 0-2，确认路径是 `C:\项目\projects\agenttrust` |
| 弹窗里找不到这个路径 | 路径打错了 | 直接复制 `C:\项目\projects\agenttrust` 粘贴进去 |

# 第 1 步：打开终端，确认位置

### 为什么要这样做

**每次敲命令之前，先确认自己站在哪里。** 这一个习惯能省掉你以后 80% 的报错。

### 要做什么

| 序号 | 操作 | 说明 |
|---|---|---|
| 1-1 | 按 **`` Ctrl + ` ``** | 反引号键，在键盘左上角 `1` 的左边、`Tab` 的上边 |
| 1-2 | 终端出现在下方 | 可能显示 `PowerShell` |
| 1-3 | 输入 `pwd` 然后回车 | pwd = print working directory（显示当前目录） |

### ✅ 应该看到

```
C:\项目\projects\agenttrust
```

### ❌ 出错怎么办

| 现象 | 怎么办 |
|---|---|
| 显示的是别的路径 | 输入 `cd C:\项目\projects\agenttrust` 然后回车，再敲一次 `pwd` |
| 找不到终端 | 按 `` Ctrl + ` `` 再试；或菜单 `查看 → 终端` |

# 第 2 步：体检 —— 确认项目是好的

### 为什么要这样做

项目里有 **204 个自动检查**。跑一遍就知道项目有没有坏。
**以后你每次改完代码，都先跑这一句。绿色才继续，红色就停下来问人。**

### 要做什么

在终端粘贴这一行，回车：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

这一行拆开看是什么意思：

| 部分 | 含义 |
|---|---|
| `.\.venv\Scripts\python.exe` | 用项目自己的 Python（不是系统那个） |
| `-m pytest` | 运行 pytest 这个测试工具 |
| `-q` | quiet，只显示简要结果 |

### ✅ 应该看到

```
204 passed in 0.63s
```

**只要看到 `204 passed` 就是好的。**（后面的秒数可能不同）

### ❌ 出错怎么办

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `无法将".\.venv\..."项识别` | 终端站错文件夹 | 回到第 1 步，`pwd` 确认位置 |
| `204` 变成别的数字，或有红色 `FAILED` | 项目被改动过 | **截图发我，不要自己改** |
| 一堆红色报错 | 同上 | **整段复制发我** |

# 第 3 步：跑实验 —— 看那张成绩单

### 这一步在干什么（重要，理解了才不会懵）

你的项目做了一个**比赛**，让三种"选人策略"在同一条件下比高低：

| 策略 | 它怎么选人 | 好比是 |
|---|---|---|
| 随机选择 | 闭着眼睛挑一个 | 「我随便找个」 |
| 仅能力匹配 | 只看谁技能合、谁快 | 「我只看简历」 |
| **可信度感知** | 技能 + **真实战绩** + 速度 | 「我看简历，还查背景」 |

**这一步就是把比赛跑一遍，看谁赢。**

### 要做什么

在终端粘贴这一行，回车：

```powershell
.\.venv\Scripts\python.exe run_experiment.py
```

### ✅ 应该看到

一张表格，长这样（数字可能极小差别）：

```
============================================================================================
实验结果汇总
============================================================================================
参数：5 次独立试验 × 100 轮 × 3 种策略 = 共 1500 次调度决策
任务需求能力：['research'] ｜ 随机种子：42

策略                   任务成功率        欺骗被选中率       前期被骗率       后期被骗率        平均延迟
--------------------------------------------------------------------------------------------
仅能力匹配              16.20%       100.00%     100.00%     100.00%      150.0ms
随机选择               58.40%        29.20%      29.00%      29.25%      259.8ms
可信度感知              78.40%         1.20%       6.00%       0.00%      324.4ms
--------------------------------------------------------------------------------------------
```

下面还有一行行"结果已保存：..."，那是文件路径。

### 🔍 这张表怎么读

| 列名 | 什么意思 | 好的方向 |
|---|---|---|
| 策略 | 三种选人规矩 | —— |
| **任务成功率** | 派出去的活，干成的比例 | **越高越好** |
| **欺骗被选中率** | 选中那个吹牛智能体的比例 | **越低越好** |
| 前期被骗率 | 前 20 轮里被骗的比例 | 越低越好 |
| 后期被骗率 | 20 轮之后被骗的比例 | 越低越好 |
| 平均延迟 | 平均等多久 | 越低越好（但要和成功率一起看） |

### ⭐ 三个必须记住的结论

1. **「仅能力匹配」只有 16.20%，比「随机选择」的 58.40% 还差** —— 只看简历反而最糟
2. **「可信度感知」78.40%，欺骗被选中率只有 1.20%** —— 你的方案赢了
3. **20 轮之后被骗率降到 0.00%** —— 系统真的学会了识别骗子

### ❌ 出错怎么办

| 现象 | 怎么办 |
|---|---|
| 报错找不到文件 | 回到第 1 步确认位置 |
| 表格里数字和上面差很多 | 可能种子不同。先截图发我，别急着下结论 |

# 第 4 步：用 Excel 打开结果看看

### 为什么要这样做

刚才终端里只是"打印"出来了。真正的**原始数据**存成了文件，
参赛要求保存原始实验记录 —— 这些文件就是你的证据。

### 要做什么

| 序号 | 操作 |
|---|---|
| 4-1 | VS Code 左侧展开 `results` 文件夹 |
| 4-2 | 找到 `..._summary.csv` 结尾的那个文件，**右键 → 在文件资源管理器中显示** |
| 4-3 | 双击用 Excel 打开 |
| 4-4 | 看看每一列是什么 |

### ✅ 应该看到

Excel 里一行一个策略，列名和终端表格一致：

| strategy | total_rounds | task_success_rate | deceptive_selection_rate | ... |
|---|---|---|---|---|
| capability_only | 500 | 0.162 | 1.0 | ... |
| random | 500 | 0.584 | 0.292 | ... |
| trust_aware | 500 | 0.784 | 0.012 | ... |

**试试画图**：选中 `strategy` 那列和 `task_success_rate` 那列 → 菜单 `插入` → `柱状图`。
这就是你参赛报告里的对比图。

### `results` 文件夹里三个文件分别是什么

| 文件名 | 内容 | 用途 |
|---|---|---|
| `..._rounds.csv` | 1500 行，每一次决策的详细记录 | **参赛要求的原始数据** |
| `..._summary.csv` | 3 行，每个策略的汇总 | 画对比图用 |
| `..._meta.json` | 实验参数、智能体设定、已知局限 | 证明实验可复现 |

# 第 5 步：回答问题（检验有没有真懂）

### 为什么这一步最重要

比赛要的是**你们能解释自己的项目**。
一个讲不明白的复杂系统，不如一个讲得清楚的简单系统。

**不要翻文档，用自己的话答。答成什么样都行，哪怕只有一句。**

### 三个问题（由易到难）

| # | 问题 | 提示 |
|---|---|---|
| 1 | 为什么不能相信智能体自己声称的成功率？ | 想想那个"说自己 99%、实际 1 胜 7 负"的家伙 |
| 2 | 可信度公式 `(成功+2)/(成功+失败+4)` 里的 **2 和 4** 有什么用？ | 想想一个刚来的、没有任何战绩的新人，该给几分 |
| 3 | 为什么"仅能力匹配"策略比"随机选择"还差？ | 想想这三个人的技能是不是都一样 |

### 补充阅读

# 附：常用命令速查（不用背，用到再回来查）

**打开终端前，先确认位置：**

```powershell
pwd
```

**如果位置不对，走进项目文件夹：**

```powershell
cd C:\项目\projects\agenttrust
```

**体检（每次改完代码都跑）：**

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

**跑实验（默认规模）：**

```powershell
.\.venv\Scripts\python.exe run_experiment.py
```

**快速跑实验（1 次试验 50 轮，几秒出结果）：**

```powershell
.\.venv\Scripts\python.exe run_experiment.py --trials 1 --rounds 50
```

**启动服务，用浏览器点着玩：**

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

然后浏览器打开 http://127.0.0.1:8000/docs
（用完按 `Ctrl + C` 停止）

**不激活虚拟环境也能用**：上面所有命令都是直接指定 `.venv` 里的 python，
所以**不需要**先运行 `Activate.ps1`。这也是为了避免 PowerShell 的执行策略问题。
