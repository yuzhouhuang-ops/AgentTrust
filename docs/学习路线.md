# 第一节：需要掌握的技能（按重要性排序）

## 🔴 第一优先：必须会（不会就做不下去）

| # | 技能 | 用在哪 | 需要到什么程度 |
|---|---|---|---|
| 1 | **函数 `def`** | 到处都是 | 会定义、会调用、知道参数和返回值 |
| 2 | **列表 list 和字典 dict** | 存智能体、存战绩 | 会增删改查、会遍历 |
| 3 | **`for` 循环** | 遍历智能体、跑轮次 | 会用 `for x in list` |
| 4 | **`if / else`** | 判断成功失败、判断匹配 | 会用，包括 `and` / `or` |
| 5 | **类 `class`** | `AgentProfile`、`AgentView` | **知道类是"打包数据和函数"**，会创建对象、会调它的方法 |
| 6 | **`import`** | 模块之间互相引用 | 知道 `from app.scoring import trust_score` 是什么意思 |
| 7 | **pip / venv** | 装依赖、隔离环境 | 会建虚拟环境、会装 requirements |

> **这 7 项是你的"入场券"。** 如果其中有不会的，先补，别硬上。

## 🟠 第二优先：这个项目新引入的（边做边学）

| # | 技能 | 用在哪 | 为什么需要 |
|---|---|---|---|
| 8 | **`@property` 装饰器** | `scoring.py`、`simulator.py` | 让一个方法"看起来像变量"，比如 `p.actual_success_rate` |
| 9 | **`@dataclass`** | `simulator.py`、`experiment.py` | 少写一堆样板代码，自动生成初始化方法 |
| 10 | **类型注解 `-> float`** | 到处都是 | 标明"这个函数返回小数"，减少出错 |
| 11 | **列表推导式** | `experiment.py` 最多 | `[x.name for x in agents]` 一行干完循环+收集 |
| 12 | **`f-string` 格式化** | 打印输出 | `f"成功率 {rate:.2%}"` 把小数显示成百分比 |
| 13 | **字典推导式** | 汇总统计 | `{a.name: a for a in agents}` |
| 14 | **`try / raise / except`** | 参数校验 | 参数不合法时主动报错，而不是算出垃圾数据 |
| 15 | **`__init__` 构造方法** | 各个类 | 创建对象时自动跑，用来初始化 |

> **这 8 项不用先学完再动手。** 建议做法：**看到不懂的语法，回来查这一行**。

## 🟡 第三优先：工具类（会用就行，不用懂原理）

| # | 工具 | 用途 | 学会要多久 |
|---|---|---|---|
| 16 | **pytest** | 跑那 204 个测试 | 会敲 `-m pytest` 就够用了 |
| 17 | **FastAPI** | 把函数变成网页接口 | 知道 `@app.get("/")` 是"访问这个网址就执行这个函数" |
| 18 | **Pydantic** | 校验请求数据格式 | 知道它能自动拦掉非法输入（返回 422） |
| 19 | **uvicorn** | 启动网站服务 | 会敲启动命令就行 |
| 20 | **CSV / JSON** | 存实验结果 | 知道 CSV 能用 Excel 打开 |

## ⚪ 不需要掌握的（这点很重要，别被吓到）

| 不需要的东西 | 说明 |
|---|---|
| ❌ 机器学习 / 深度学习 | **完全不用**。核心公式只有一行加减乘除 |
| ❌ 大模型训练 / 微调 | **完全不用** |
| ❌ GPU / CUDA | **完全不用** |
| ❌ Docker / Kubernetes | **完全不用** |
| ❌ 数据库 | 目前用内存字典，还没接数据库（SQLite 是计划中的可选项） |
| ❌ 前端 React / Vue | 不需要，FastAPI 自带 `/docs` 页面可以点着操作 |
| ❌ 分布式 / 消息队列 | **完全不用** |

> **如果有人说"做 AI 项目必须会深度学习"，那是错的。**
